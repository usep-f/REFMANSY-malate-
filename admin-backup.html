Disaster Recovery & Offline Preservation Guidelines

Regular Snapshots:

Download a system backup weekly or before major semester end reporting cycles.

Offsite Storage:

Store exported .zip files on an encrypted external drive or dedicated school backup server.

Checksum Verification:

Every backup contains SHA-256 hashes inside manifest.json to guarantee zero corruption or tampering.

Critical Action: System Restore Confirmation

This action will replace the current database with the selected snapshot.

Please read carefully before proceeding:

Restoring will purge current database records and replace them with the records in the backup archive. Any research files or user activity added after the snapshot date will be overwritten.
